# Citation Hallucination

This repository contains data, scripts, and analysis artifacts for studying citation hallucination behavior across models.

## Layout
- `data/`: input datasets and intermediate artifacts
- `scripts/`: data processing and evaluation utilities
- `out/`: generated outputs and analysis results
- `src/`: source code

## Quick Start
1. Run the relevant scripts in `scripts/` to generate outputs.
2. Inspect generated results in `out/`.

## Notes
Large generated files may be created under `out/` during analysis.
